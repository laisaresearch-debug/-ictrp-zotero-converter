ICTRP → Zotero

Converte o XML original da WHO ICTRP para RIS, com mapeamento dos campos dos ensaios clínicos. Funciona localmente no navegador: o arquivo não é enviado a nenhum servidor.

Selecione um arquivo para começar.

Prévia do primeiro registro


Importação no Zotero: Arquivo → Importar → Um arquivo → selecione o .ris baixado. Registros de ensaios clínicos são classificados como Relatório, não como artigos publicados. A data de registro não é a data de publicação.
Controle de qualidade: compare a quantidade de registros e pelo menos 3 títulos/IDs com o arquivo original. Se algum campo faltar, mantenha o XML e envie-o para correção do mapeamento.
